# 系统架构设计师 · 备考助手

一个面向手机浏览器、可离线使用的软考高级「系统架构设计师」备考网页应用。包含开箱即学的知识讲义、按天排好的课程、688 道题库、记忆卡、案例分析与论文指南，学习进度保存在本机浏览器中。

- 在线地址：https://github.com/volcanochen/SrArchTest
- 应用目录：`exam-app/`

---

## 一、功能概览

| 模块 | 说明 |
| --- | --- |
| 首页 | 考试倒计时、总复习进度环、连续打卡、知识掌握度、刷题正确率、三科进度、今日课程 |
| 课程 | 27 节课按天排期，内联展示当日学习内容，学完立即测试 |
| 知识 | 13 个知识模块、74 个知识点，每个知识点含讲解、例子、记忆要点、易错提醒 |
| 练习 | 688 道题库（多维筛选）、间隔重复记忆卡、案例分析框架、论文指南 |
| 我的 | 学习统计、考试日期设置、清空进度 |

题库构成：

- 原创专项练习：441 题
- 历年题社区整理版：247 题（2021—2025）

每题都包含：题目解读、答案解析、题目来源、解读来源、所属模块、年份、难度。

> 说明：历年题统一标注为「历年真题 · 社区整理」，属于考后回忆/复原/转述性质的社区开源整理资料，**不是考试机构发布的官方原卷**。

## 二、在手机上使用

### 方式一：发布为在线网页（推荐）

这是最方便的方式，手机扫码或点开链接即可使用，还能「添加到主屏幕」像 App 一样打开。

1. 打开仓库：https://github.com/volcanochen/SrArchTest
2. 进入 **Settings → Pages**
3. 在 **Source** 中选择 `Deploy from a branch`
4. 分支选择 `main`，目录选择 `/ (root)` 或 `/docs`
5. 保存后等待几分钟，会得到类似地址：

   ```
   https://volcanochen.github.io/SrArchTest/
   ```

6. 如果应用放在 `exam-app/` 目录，访问：

   ```
   https://volcanochen.github.io/SrArchTest/exam-app/index.html
   ```

提示：如果想让根路径直接打开应用，可以把 `exam-app/` 下的文件移动到仓库根目录，或在根目录 `index.html` 中做一个跳转。

添加到主屏幕：

- iPhone：Safari 打开页面 → 分享 → 添加到主屏幕
- Android：Chrome 打开页面 → 右上角菜单 → 添加到主屏幕 / 安装应用

### 方式二：把文件夹传到手机，直接打开

1. 把 `exam-app/` 整个文件夹复制到手机（微信文件传输、数据线、网盘均可）
2. 在手机上用文件管理器进入该目录
3. 点击 `index.html`，选择用浏览器打开

要求：`index.html`、`css/`、`js/` 三个部分的相对目录结构必须保持完整，不能只复制单个 HTML 文件。

注意：这种 `file://` 方式在某些手机浏览器上可能限制本地存储，进度保存不如在线方式稳定。

### 方式三：手机部署为本地服务（可选）

适合不希望上传到公网、又想要稳定存储的场景。

1. 在手机或电脑上运行任意静态服务器，例如：

   ```bash
   cd exam-app
   python -m http.server 8000
   ```

2. 手机与电脑在同一局域网时，浏览器访问：

   ```
   http://电脑IP:8000
   ```

## 三、在电脑上使用

直接双击 `exam-app/index.html` 即可，或用本地服务器：

```bash
cd exam-app
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 四、目录结构

```
SrArchTest/
├── README.md
├── exam-app/
│   ├── index.html              # 应用入口
│   ├── css/style.css           # 移动优先样式
│   ├── js/data.js              # 知识讲义、计划、案例与论文指南
│   ├── js/app.js               # 交互、进度、课程、题库逻辑
│   ├── js/question-bank.js     # 688 题扩展题库（自动生成）
│   └── tools/
│       └── build_question_bank.py  # 题库生成脚本
└── .workbuddy/                 # 项目记忆与原始资料
```

加载顺序在 `index.html` 中为：

```html
<script src="js/data.js"></script>
<script src="js/question-bank.js"></script>
<script src="js/app.js"></script>
```

## 五、重新生成题库

修改知识讲义或更新历年题原始资料后，执行：

```bash
python exam-app/tools/build_question_bank.py
```

脚本会重新生成 `exam-app/js/question-bank.js`。

说明：

- 题库由 `data.js` 中的知识点自动生成分层专项练习
- 历年题来自 MIT License 的社区开源整理仓库 `himozhang/system-architect-exam`
- 生成时会自动去重，并保持每题的来源与解读字段完整

## 六、数据保存与隐私

- 进度保存在浏览器 `localStorage` 中，不上传服务器
- 更换浏览器、清理浏览数据或使用隐私模式可能导致进度丢失
- 同一手机换浏览器打开，进度不会自动同步
- 应用为纯静态页面，无后端、无账号、无埋点

## 七、考试信息备忘

- 综合知识：75 道单选题，约 150 分钟
- 案例分析：5 选 3，约 90 分钟
- 综合知识与案例分析连考，约 240 分钟
- 论文：约 120 分钟，2500 字左右
- 三科满分均为 75 分，均须达到 45 分，且须同次考试全部通过

考试日期请以官方公告为准，应用内可在「我的 → 考试日期」中修改。
